OBP Bank Node

Join a payment corridor from your own data centre.

OBP Bank Node is a small service that runs inside your bank and connects your core banking system to cross-border payment corridors using the Open Corridor standard, with a private, verifiable record of every step and no OBP infrastructure of your own to run.

A payment, step by step

  1. SendYour core banking system sends a payment to the node, in the shape of an OBP transaction request, and gets an answer in milliseconds.
  2. PromiseThe node records a promise on Cardano: a salted fingerprint, with no amounts, names or personal data.
  3. CreditThe receiving bank's node checks the fingerprint, then delivers the credit to its own core banking system.
  4. SettleBanks settle what they owe each other, and the node follows each settlement until it is final.

What it does

  • Speaks OBPPayments arrive as OBP transaction requests, routed by BIC and IBAN, mobile number or OBP account
  • Never loses a paymentA durable outbox keeps every request until OBP-API has it
  • Private on-chain recordsOnly a salted fingerprint goes on Cardano; anyone entitled can check it, nobody else learns anything
  • Delivers credits your wayA webhook in OBP or ISO 20022 camt.054 format, a database table, or a file drop, retried for a day
  • Handles refusalsA credit your system refuses becomes a linked return that offsets the original payment
  • Shows the evidenceRead APIs, and a web page that follows each payment from send to settle

Built for banks

  • Outbound connections onlyRuns inside your network; nothing needs to reach in
  • Your keysYou hold your own keys and run your own Cardano node
  • SmallOne binary, a Docker image of about 20 MB, and under 50 MB of memory
  • A Platform AppEach node declares the Scopes it needs, and sees only the accounts it is given

Run it

  • RustOne service, with SQLite for its outbox
  • Docker imagesOne per Cardano network, with Compose files that run the node beside cardano-node and Ogmios
  • Configured in one fileA YAML file, with any setting overridable by environment
  • Open sourceAGPL on GitHub, with commercial licences from TESOBE
