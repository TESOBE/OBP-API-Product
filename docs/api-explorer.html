API Explorer

Every endpoint, documented and callable.

API Explorer shows every endpoint OBP-API serves, with the Roles it needs and the errors it can return, and lets you call it there and then.

What you can do

  • Browse by version and standardOBP versions, UK Open Banking, Berlin Group and every other standard OBP-API serves, filtered by tag
  • Read each endpointThe request, a typical response, validations, the errors it can return and the connector methods behind it
  • See the Roles it needsAnd ask for a missing Role from the same page
  • Call it as yourselfSend the request with your own login, and edit the JSON body as you go
  • Dynamic endpoints tooEndpoints you create in OBP-API appear beside the built-in ones, documented the same way
  • The glossaryEvery OBP term explained, from ABAC to Views
  • Message docsThe messages a connector exchanges with your core banking system, with their JSON schemas
  • gRPC and collectionsThe gRPC services, and API collections people have shared

For everyone who works with the API

  • DevelopersFind the right endpoint and try it before writing a line of code
  • Bank staffSee exactly which Role each endpoint needs, and why a call was refused
  • Connector buildersRead the message docs for each core banking integration
  • Regulators and partnersRead the whole API surface, in English, Spanish or Romanian

Run it

  • Any OpenID Connect providerOBP-OIDC, Keycloak, Google, GitHub or your own, discovered from OBP-API
  • Two imagesopenbankproject/api-explorer-ii and api-explorer-ii-nginx, configured when the container starts
  • Vue and ExpressVue 3 in the browser, an Express server beside it
  • Open sourceAGPL on GitHub, with commercial licences from TESOBE
