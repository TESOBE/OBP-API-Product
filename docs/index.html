Open Bank Project API

The open source API platform for banks.

OBP-API gives banks, fintechs and regulators one modern API across every core banking system: accounts, payments, customers and consents, with the open banking standards built in and access decided on every call.

What you can build

OBP-API covers the whole of a bank's API: what customers and partners use, and what the bank runs it with.

Accounts and payments

Everything a bank account does

Accounts, balances, transactions, counterparties, standing orders, direct debits and payment requests with strong customer authentication.

Banking features

Customers

Customers, KYC and files

Customer records, KYC checks, documents and photographs stored safely and attached to the records they belong to.

Customer features

Extend

Your own APIs, without a release

Define new data and endpoints at run time, and publish them as an API of their own with its own OpenAPI document.

Dynamic APIs

Control

Access decided on every call

Views decide which fields each party sees. Roles decide which endpoints they may call. Consents let customers decide who sees what.

Security and control

Standards

The Open Bank Project API, Berlin Group NextGenPSD2 and UK Open Banking, served by the same platform from the same data.

Connect

Any core banking system

Connectors reach your systems over REST, RabbitMQ, gRPC, Akka or stored procedures, and Bank Nodes connect banks from inside their own networks.

Endpoints by area

Every endpoint is documented in the API itself, with examples, the Roles it needs and the errors it can return.

    How it fits together

    Applications call OBP-API. OBP-API applies the standards and the access rules, then reaches each bank's own systems through connectors.

    The architecture

    Why OBP-API

    • Open source since 2010The code is on GitHub under the AGPL, with commercial licences for banks that need them
    • Bank as a platformOne API across many banks, so apps and partners integrate once
    • Built for regulatorsUsed for open banking regulation, regulatory sandboxes and conformance testing
    • Transparency as an assetCustomers see and control who has access to their data, and why
    • Ready for AI agentsOpey and the OBP-MCP server let AI agents find and call endpoints, with the user's own permissions
    • Operations built inTelemetry, API metrics, rate limits, deployment checks and traffic analysis
