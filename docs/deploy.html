Deploy

Run it on your own infrastructure.

OBP-API is one executable JAR. Run one instance for a sandbox, or many behind a load balancer for production.

From code to running platform

  1. Get the codeClone OBP-API from GitHub. You need JDK 25 and Maven.
  2. Choose a database and a connectorSet the database, the connector and the identity provider in the props file, starting from sample.props.template.
  3. Build and runMaven builds one executable JAR. Run it on its own, in Docker or in Kubernetes.
  4. Add the appsRun API Explorer, API Manager and the Portal beside it, and mark them as Platform Apps. Fill a sandbox with the Sandbox Populator.
  5. Watch itTurn on Telemetry, read the deployment checks, and let OBP Senti keep an eye on it.
